# Badge

Compact label for statuses, counts, and tags-without-actions.

```tsx
<Badge variant="success" dot>Active</Badge>
<Badge variant="primary">Beta</Badge>
```

| Prop      | Type                                                                    | Default     |
| --------- | ----------------------------------------------------------------------- | ----------- |
| `variant` | `'neutral' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'outline' \| 'solid'` | `'neutral'` |
| `size`    | `'sm' \| 'md' \| 'lg'`                                                  | `'md'`      |
| `dot`     | `boolean`                                                               | `false`     |
